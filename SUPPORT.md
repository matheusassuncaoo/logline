# Support

## English

Use the project host's issue tracker for reproducible bugs and focused feature requests once a public repository is available.

Before opening a report, check the README, existing issues, and documentation. Include the following when relevant:

- A clear description of the problem or requested workflow.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Operating system and whether you used `npm run dev`, `npm run tauri dev`, or a packaged build.
- Screenshots, recordings, or logs that do not contain private data.
- Whether the issue affects newly created or existing local workspaces and boards.

Do not report security vulnerabilities through a public issue. Read [SECURITY.md](SECURITY.md) instead.

## Português (Brasil)

Use o rastreador de issues da plataforma do projeto para bugs reproduzíveis e sugestões de funcionalidades objetivas quando houver um repositório público disponível.

Antes de abrir um relato, consulte o README, as issues existentes e a documentação. Inclua o que for relevante:

- Uma descrição clara do problema ou fluxo solicitado.
- Passos para reproduzir o erro.
- Comportamento esperado e comportamento atual.
- Sistema operacional e se você usou `npm run dev`, `npm run tauri dev` ou um build empacotado.
- Screenshots, gravações ou logs que não contenham dados privados.
- Se o problema afeta workspaces e boards novos ou dados locais existentes.

Não reporte vulnerabilidades de segurança em uma issue pública. Leia [SECURITY.md](SECURITY.md).
