# Code of Conduct

## Our Commitment

We want LogLine to be a respectful, practical, and welcoming open source project.

Queremos que o LogLine seja um projeto open source respeitoso, prático e acolhedor.

People should be able to participate regardless of experience level, background, identity, location, language, or tooling preferences.

Pessoas devem poder participar independentemente de experiência, origem, identidade, localização, idioma ou preferência de ferramentas.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections quickly.
- Keep discussions focused on the project and the work.
- Give clear technical feedback without personal attacks.
- Credit ideas, reports, and contributions fairly.
- Help newcomers understand the repository and contribution process.

## Unacceptable Behavior

- Harassment, threats, stalking, or intimidation.
- Insults, slurs, or discriminatory language.
- Sexualized comments or imagery in project spaces.
- Publishing private information without permission.
- Repeated off-topic disruption.
- Bad-faith behavior intended to waste maintainer or contributor time.

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, discussions, documentation, chat, releases, and community spaces connected to LogLine.

Este código se aplica a todos os espaços do projeto, incluindo issues, pull requests, discussões, documentação, chats, releases e comunidades relacionadas ao LogLine.

## Reporting

If you experience or witness unacceptable behavior, report it to the project maintainer or owner through the most appropriate private channel available for the repository.

Se você presenciar ou sofrer comportamento inadequado, reporte ao mantenedor ou proprietário do projeto pelo canal privado mais adequado disponível no repositório.

Include relevant context, links, screenshots, or timestamps when possible.

## Enforcement

Maintainers may take action that fits the situation, including warnings, comment deletion, temporary restrictions, issue or PR locking, or permanent bans from project spaces.

Mantenedores podem agir conforme a situação, incluindo avisos, remoção de comentários, restrições temporárias, bloqueio de issues ou PRs, ou banimento permanente dos espaços do projeto.
