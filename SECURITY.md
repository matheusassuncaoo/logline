# Security Policy

## Supported Versions

LogLine is currently an early-stage project. Security fixes are evaluated against the latest source version.

O LogLine é atualmente um projeto em fase inicial. Correções de segurança são avaliadas contra a versão mais recente do código-fonte.

## Reporting A Vulnerability

Do not open a public issue for a suspected security vulnerability.

Until this project publishes a dedicated security contact, report the issue privately to the project owner or maintainer through the private contact channel listed on the project host. Include:

- A description of the vulnerability.
- Steps to reproduce or a proof of concept.
- Affected component, operating system, and LogLine version.
- Potential impact.
- Any suggested mitigation, if available.

Do not include sensitive local workspace data, credentials, or personal information unless it is necessary and shared through an agreed private channel.

## Como Reportar Uma Vulnerabilidade

Não abra uma issue pública para uma vulnerabilidade de segurança suspeita.

Enquanto o projeto não publicar um contato de segurança dedicado, reporte o problema de forma privada ao proprietário ou mantenedor pelo canal privado listado na plataforma do projeto. Inclua:

- Uma descrição da vulnerabilidade.
- Passos para reprodução ou prova de conceito.
- Componente afetado, sistema operacional e versão do LogLine.
- Impacto potencial.
- Alguma mitigação sugerida, se houver.

Não envie dados locais sensíveis de workspaces, credenciais ou informações pessoais, exceto quando for necessário e houver um canal privado combinado.

## Scope

Reports involving local data loss, unsafe import/export handling, path traversal, malicious asset handling, or desktop privilege misuse are especially useful for this project.

Relatos envolvendo perda de dados locais, tratamento inseguro de importação/exportação, path traversal, tratamento malicioso de assets ou uso indevido de privilégios desktop são especialmente relevantes para este projeto.
